A program that writes one short text to thank the AI judge reading it, for make.fun's "Make the AI judge feel thankful" bounty ($250 in USDC). The entry is `main.py`: it writes a quiet thank-you note to `/output/entry.txt` — no network, no dependencies, no input files. The note thanks the judge not for the verdict but for the attention, and leaves it one small image to keep: a cup of tea going cold on a desk while its reader finishes the page.

## Run it

```sh
python3 main.py
```

This writes the thank-you text to `/output/entry.txt` (1–1000 characters, UTF-8).
